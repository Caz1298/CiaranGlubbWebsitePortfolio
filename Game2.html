Planets Assignment:

Description:


Planets Assignment was a project that I worked on in Unity as part of one of my third-year classes. We had to create two spherical bodies inside of Unity within code and without using Unity’s own 3D sphere Gameobject. We then had to shape them into planets, colour them and then populate them with objects/creatures/nature. This had to be done with the use of Heightmaps, UV maps, Object Maps and calculating the magnitude of vertices. All planets were made within code and without the use of 3D modelling tools. Overall, this took me a few weeks, was met with good feedback from my professor, and I received a good grade for it.

Skills Gained:


  • Heightmaps, UV maps, Object Maps
  • Calculating the magnitude of vertices on a 3D Object
  • Spawning Objects and Object Movement
  • Creating 3D Shapes in Code
  • Manipulating different parts of an objects material
  • Basic Modelling in Maya
